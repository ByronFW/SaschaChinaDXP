# China DXP — RG experience

An interactive presentation for Sascha: a US-to-China Pimcore content architecture, detailed map, and discovery questions.

Open the published presentation at https://byronfw.github.io/SaschaChinaDXP/.

The site uses static HTML, CSS, JavaScript, and a local logo. It requires no account or external runtime libraries. Discussion notes are stored only in the visitor's browser and can be exported. The full workshop is available through the footer.

The architecture is a working concept for discussion, not a validated implementation plan.
